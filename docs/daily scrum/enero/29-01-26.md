### Estructura del Nodo CoT
```python
def thinking_node(state):
    """Genera razonamiento visible antes de la respuesta."""
    prompt = build_cot_prompt(state["question"], state["context"])
    response = llm.invoke(prompt)
    return {"thinking": response.thinking, "answer": response.answer}
```
