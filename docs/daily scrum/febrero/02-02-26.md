# Daily Scrum — 2 de febrero de 2026

## 🎯 Objetivo hoy
Mejorar el análisis de respuestas y el feedback pedagógico, utilizando el contexto RAG como apoyo sin depender exclusivamente de él.

---

## ✅ ¿Qué hice anteriormente? (31-01-26)

- Planificación inicial de la integración RAG para tests.
- Actualización del Sprint Planning 6 para incluir mejoras en la herramienta de test.

## 🚀 ¿Qué haré hoy?

1. **Mejora del Feedback en Test**:
   - Actualizar `evaluate_answer_with_llm` para que utilice el contexto RAG como información de apoyo, sin depender exclusivamente de él.
   - Refinar el prompt `TEST_EVALUATION_PROMPT` para que el LLM use su razonamiento propio complementado con el material del RAG cuando esté disponible.

2. **Validación de Calidad**:
   - Realizar pruebas manuales para asegurar que el feedback sea coherente, aprovechando el RAG como contexto útil pero manteniendo capacidad de evaluación independiente.

## 🚧 Obstáculos potenciales

- Respuestas ambiguas de los alumnos que dificulten la evaluación automática.
- Balancear el uso del contexto RAG sin crear dependencia total en él.
- Asegurar que el feedback sea alentador y no solo correctivo.

## ✅ Criterios de aceptación

- [x] Proceso de evaluación mejorado que usa RAG como contexto complementario.
- [x] El LLM puede evaluar correctamente incluso si el RAG no proporciona información relevante.
