# Daily Scrum - 17 de Noviembre 2025 (Refactorización a Chatbot Service)

## 🎯 Objetivo hoy
Transformar el monolito `backend` actual en un microservicio especializado llamado `chatbot`.

---

## ✅ ¿Qué hice ayer (Viernes)?

- Implementé el `auth_service` con registro y login funcional.
- Solucioné problemas de dependencias con `bcrypt`.

## 🚀 ¿Qué haré hoy?

1. Renombrar el directorio `backend` a `chatbot`.
2. Actualizar `pyproject.toml` y `Dockerfile` para reflejar el cambio de nombre.
3. Refactorizar todos los imports internos (de `backend.x` a `chatbot.x`).
4. Actualizar `docker-compose.yml` para levantar el servicio `chatbot` en el puerto 8080.
5. Verificar que la lógica del agente (LangGraph) sigue funcionando tras la mudanza.

## 🚧 Obstáculos potenciales

- Gran cantidad de imports rotos al renombrar el paquete raíz.
- Referencias cruzadas en tests que pueden fallar.

## ✅ Criterios de aceptación

- El servicio `chatbot` compila y arranca correctamente.
- Los tests unitarios del agente pasan con los nuevos imports.
- El servicio es accesible internamente vía HTTP.

## 📝 Notas / Próximos pasos

- Mañana crearé el nuevo `backend` que actuará como API Gateway unificando Auth y Chatbot.
