Dashboard de Tópicos: implementar mapa de conceptos interactivo.

- Tooltip con detalles al hover funcionando.
- Scroll horizontal implementado para datasets grandes.

## 🚀 ¿Qué haré hoy?

1. **Mapa de conceptos interactivo** ([#129](https://github.com/GabrielFranciscoSM/TFG-Chatbot/issues/129)):
   - Implementar grafo interactivo con D3.js o react-force-graph.
   - Nodos = tópicos (tamaño proporcional al nº de documentos).
   - Aristas = co-ocurrencia en documentos.
   - Interacciones: zoom, drag, hover con detalles del tópico.
   - Colores por tópico consistentes con la lista y el heatmap.

2. **Pulido del Dashboard** ([#129](https://github.com/GabrielFranciscoSM/TFG-Chatbot/issues/129)):

   - Layout responsive para las tres vistas (lista, heatmap, grafo).
   - Manejo de estados: sin tópicos, extrayendo, error.
