# Daily Scrum - 11 de Noviembre 2025 (Buenas prácticas y CI)

## 🎯 Objetivo hoy
Asegurar que las buenas prácticas estén en el flujo de desarrollo: pre-commit, linters en CI y protección de ramas.

---

## ✅ ¿Qué hice ayer?

- Identifiqué gaps en CI: falta de jobs para linter y comprobación de base de PR.
- Recopilé ejemplos de workflows para validar branch policy.

## 🚀 ¿Qué haré hoy?

1. Añadir pre-commit hooks recomendados (ruff, isort, black) y documentar instalación.
2. Crear un workflow de CI que incluya jobs de linter y tests básicos.
3. Documentar la política de ramas en `CONTRIBUTING.md` o `docs/process.md`.

## 🚧 Obstáculos potenciales

- Algunos desarrolladores podrían necesitar ayuda para instalar hooks locales.
- Ajustes en CI pueden requerir iteración para estabilizar tiempos y caches.

## ✅ Criterios de aceptación

- Pre-commit instalable y funcional con un comando.
- CI ejecuta linter y tests en PRs (dirigidos a `development`).
- Documentación de políticas visible en repo.

## 📝 Notas / Próximos pasos

- Probar el flujo con un PR de ejemplo apuntando a `development`.
- Añadir check en PR template indicando la base correcta.
