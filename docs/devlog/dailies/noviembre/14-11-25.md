# Daily Scrum - 14 de Noviembre 2025 (Servicio de Autenticación)

## 🎯 Objetivo hoy
Implementar el microservicio dedicado a la autenticación y autorización (`auth_service`).

---

## ✅ ¿Qué hice ayer?

- Diseñé la arquitectura de microservicios (Gateway, Auth, Chatbot).
- Definí los contratos de comunicación entre servicios.

## 🚀 ¿Qué haré hoy?

1. Crear la estructura del proyecto `auth_service` (FastAPI).
2. Implementar modelos de usuario y lógica de hashing de contraseñas (`passlib`, `bcrypt`).
3. Implementar endpoints de `/register` y `/token` (Login).
4. Configurar la conexión a MongoDB independiente para usuarios.
5. Dockerizar el servicio.

## 🚧 Obstáculos potenciales

- Problemas de compatibilidad con versiones recientes de `bcrypt` y `passlib`.
- Configuración correcta de la conexión a MongoDB desde un contenedor nuevo.

## ✅ Criterios de aceptación

- Servicio `auth_service` levantado en puerto 8083.
- Posibilidad de registrar usuarios y obtener tokens JWT válidos.
- Persistencia de usuarios en MongoDB.

## 📝 Notas / Próximos pasos

- El lunes procederé a refactorizar el backend actual para convertirlo en el servicio `chatbot`.
