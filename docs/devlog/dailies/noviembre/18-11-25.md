# Daily Scrum - 18 de Noviembre 2025 (Implementación del API Gateway)

## 🎯 Objetivo hoy
Crear el nuevo servicio `backend` que actuará como API Gateway y orquestador.

---

## ✅ ¿Qué hice ayer?

- Refactoricé exitosamente el antiguo backend a `chatbot`.
- Corregí todos los imports y referencias en el código del agente.

## 🚀 ¿Qué haré hoy?

1. Inicializar el nuevo proyecto `backend` (Gateway) con FastAPI.
2. Implementar middleware o dependencias para validar tokens JWT (verificación local o delegada).
3. Crear endpoints proxy:
    - `/register` y `/token` -> redirigen a `auth_service`.
    - `/chat` -> valida usuario y redirige a `chatbot`.
4. Configurar `docker-compose` para incluir el Gateway en el puerto 8000.

## 🚧 Obstáculos potenciales

- Latencia en la comunicación entre contenedores.
- Manejo correcto de errores y códigos de estado HTTP al hacer proxy de peticiones.

## ✅ Criterios de aceptación

- Gateway corriendo en puerto 8000.
- Rutas protegidas (`/chat`) rechazan peticiones sin token válido.
- Rutas públicas (`/login`) funcionan correctamente a través del Gateway.

## 📝 Notas / Próximos pasos

- Mañana será el día de integración final y pruebas end-to-end de todo el sistema distribuido.
