# Daily Scrum - 25 de Noviembre 2025 (Inicio Frontend y Configuración)

## 🎯 Objetivo hoy
Dar el pistoletazo de salida al desarrollo del Frontend, estableciendo una base sólida con el stack tecnológico elegido (React, Vite, Tailwind, Shadcn).

---

## ✅ ¿Qué hice ayer?
- Finalicé el Sprint Planning del Sprint 4.
- Definí la arquitectura del frontend y seleccioné las herramientas (Shadcn/ui para "own the code").

## 🚀 ¿Qué haré hoy?
1.  **Inicialización del Proyecto**:
    - Crear proyecto con `npm create vite@latest frontend -- --template react-ts`.
    - Configurar `tsconfig` y alias de rutas (`@/`).
2.  **Instalación de Estilos y UI**:
    - Configurar Tailwind CSS.
    - Inicializar Shadcn/ui (`npx shadcn@latest init`).
    - Instalar componentes base: `button`, `input`, `card`, `form`, `label`, `toast`, `sonner`.
3.  **Gestión de Dependencias**:
    - Instalar librerías core: `react-router-dom`, `@tanstack/react-query`, `axios`, `lucide-react`, `zod`, `react-hook-form`.

## 🚧 Obstáculos potenciales
- Conflictos de configuración entre ESLint/Prettier y las reglas por defecto de Vite.
- Asegurar que la estructura de carpetas (`src/components`, `src/lib`, `src/pages`) sea escalable desde el principio.

## ✅ Criterios de aceptación
- El servidor de desarrollo (`npm run dev`) arranca sin errores.
- Se puede renderizar un botón de Shadcn con estilos de Tailwind correctamente.
- Todas las dependencias están listadas en `package.json`.

## 📝 Notas / Próximos pasos
- Es crucial dedicar tiempo hoy a entender la estructura que genera Shadcn para no tener deuda técnica después.
